# Internship Task API

Kullanıcıların kayıt olup giriş yapabildiği, kendi proje ve görevlerini yönettiği NestJS REST API projesi.

## Teknolojiler

- TypeScript
- NestJS
- Prisma
- SQLite
- JWT
- Argon2
- Git

## Özellikler

- Kullanıcı kaydı
- Kullanıcı girişi
- JWT kimlik doğrulama
- Parola hashleme
- Project CRUD
- Task CRUD
- Kullanıcı bazlı veri sahipliği
- DTO doğrulama
